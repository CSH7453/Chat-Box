这是一款在 Chrome / Edge 中运行的本地导出工具。它读取你已登录的 Kimi、DeepSeek、ChatGPT、Claude、Gemini、千问、豆包等网页版历史，按你的选择生成 TXT、Markdown 或 JSON。没有账号密码采集，没有中转服务器。

开始导出 先看常见问题
01

安装扩展

  1. 把 AI对话导出助手 文件夹放在一个不会被删除的位置，例如 D:\AI对话导出\。
  2. 在 Chrome 地址栏打开 chrome://extensions；Edge 打开 edge://extensions。
  3. 打开右上角（Edge 在左侧）的「开发者模式」。
  4. 点击「加载已解压的扩展程序」，选择 AI对话导出助手 文件夹。
  5. 把「AI 对话导出助手」固定到浏览器工具栏，点击图标即可打开工作台。

如果你拿到的是 ZIP 包，请先解压再加载；不要直接选择 ZIP。更新扩展后，已打开的旧网页通常需要刷新一次。

02

登录并读取

  1. 在 Chrome / Edge 里打开任意受支持的 AI 网站（如 chat.deepseek.com、www.kimi.com、chatgpt.com），完成登录。
  2. 保持这些网页标签页开着，点击扩展图标打开「对话匣」。
  3. 在「选择对话来源」里选择对应的标签页。扩展会读取账号里的全部历史会话，不只是屏幕上看得到的几条。
  4. 历史很多时，读取需要几秒到几十秒，请保持原网页打开。

如果提示未登录或读取失败，先刷新原网页，确认网页里能看到历史记录，再回工作台点「重试」。

03

挑选要留下的对话

历史列表支持搜索、筛选和逐条勾选：

  • 整行点击即可勾选；右侧下载小图标可只导出这一条。
  • 全选会选中当前筛选结果；搜索后全选，只影响搜索命中的对话。
  • 当前 / 置顶标签帮助你快速定位正在聊的或固定的重要记录。

默认导出当前可见的对话分支。若对话里编辑过问题或重新生成过答案，被替换的旧分支不会混入正文，导出文件头部会注明省略了多少条旧分支。

04

选择格式并导出

文件格式TXT 通用易读；Markdown 保留标题、列表和代码块；JSON 保留结构化字段，适合二次处理。
单个文件全部选中对话合并成 1 个文件，带目录和分隔线。
多个文件一条对话一个文件，放在同一个下载文件夹。
单个 ZIP每条对话一个文件，全部打包进 1 个 ZIP。
多个 ZIP一条对话一个 ZIP，适合分卷归档。

格式与打包方式互相独立，共 12 种组合。导出文件默认保存到浏览器的下载目录 AI对话导出/网站名/ 下。回答正文始终导出；模型推理过程默认关闭，需要时请在导出设置中主动勾选。可勾选「文件名带日期」；UTF-8 BOM 只作用于 TXT / Markdown，JSON 始终无 BOM。

PRIVACY

它如何对待你的数据

扩展使用你浏览器里已有的登录态，在你当前打开的网站页面内调用该网站自己的接口；对话内容只在页面、扩展工作台和你的下载目录之间流动。

  • 不收集账号、密码或登录令牌，不把令牌发送到工作台或第三方。
  • 没有远端服务器，没有统计 SDK，没有广告代码。
  • 导出文件完全由浏览器在本地生成，使用标准 TXT / Markdown / JSON / ZIP 格式，随时可读。
  • 扩展本身不修改、不删除网站上的任何对话，只做读取。
FAQ

常见问题

点击图标没有反应，或看不到工作台？

先确认扩展已在 chrome://extensions（Edge 为 edge://extensions）中启用，并已固定到工具栏。也可以点击浏览器工具栏上的扩展图标。如果刚更新过扩展，刷新一次工作台页面。

提示「需要重新登录」或「登录状态已失效」？

打开对应网站，刷新页面并确认已经登录、能看到历史记录，然后回到工作台点「重试」。DeepSeek 的登录令牌保存在网页的本地存储里，刷新页面会更新它；扩展不会替你把密码发到任何地方。

历史列表只显示了一部分？

扩展会按网站的游标分页读取，通常能读取完整历史。若账号会话特别多、网络中途断开或网站限流，可能只取到一部分。先等待片刻再点「重试」；建议分批导出，避免一次选中上千条。

当前正在聊的对话没有出现在列表里？

如果对话已经发送过消息，通常会在历史列表里并带有「当前」标签。如果刚打开新对话还没发送消息，网站尚未创建记录，暂时无法导出；发送一条消息后再读取即可。

为什么导出的内容和网页上看到的不完全一样？

网页只展示当前分支，而网站服务端还保存着被编辑、重新生成替换掉的旧分支。默认只导出网页上显示的当前分支，并在文件头注明隐藏了多少旧分支。回答正文始终导出，模型推理过程默认关闭。

选择「多个文件 / 多个 ZIP」后浏览器提示下载多个文件？

这是浏览器的正常保护。允许该扩展下载多个文件即可。选择很多条对话时，建议使用「单个 ZIP」，一次下载更稳妥。

导出的 TXT 在旧版记事本里乱码？

保持「UTF-8 BOM」勾选；它会让 Windows 记事本正确识别中文。大多数现代编辑器（VS Code、Notepad++ 等）也能直接打开 UTF-8 文件。

会不会把我的对话上传到别的地方？

不会。扩展没有后端服务。它只在当前 AI 网站页面内调用该网站自己的接口，拿到数据后在本机内存里生成 TXT/ZIP，再交给浏览器下载。网络请求只发往你已登录的 AI 网站域名。

支持 Firefox 吗？

当前版本为 Chromium Manifest V3 扩展，面向 Chrome 和 Edge。Firefox 需要单独适配，暂未提供。

为什么 Grok、文心一言、混元只有「当前页」？

这几个站点目前没有稳定、可复用的完整历史接口，扩展改用页面快照：只导出当前打开的对话中已经加载出来的消息。请先滚动到最早一条再导出。它们的完整历史适配会在接口稳定后补上。

JSON 和 Markdown 有什么区别？

Markdown 适合阅读和继续编辑，会保留标题、列表、代码块等排版；JSON 是结构化数据，包含会话 ID、时间、角色、正文、思考过程等字段，适合导入其他工具或做二次处理。JSON 始终使用无 BOM 的 UTF-8，避免解析失败。

网站改版后读不出来怎么办？

AI 网站的内部接口会变化。如果错误持续出现，请更新扩展版本；你的原始对话仍在网站账号里，不会因为导出失败而丢失。也可以先在网页里手动复制重要对话作为临时备份。
